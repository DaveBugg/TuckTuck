# AGENTS.md — входная точка Kimi Code

Память проекта общая для всех агентов и живёт в **`CLAUDE.md`** + `memory/*.md`.

▶ **В начале каждой сессии прочитай `CLAUDE.md`** и следуй его ритуалу (Serena → код-граф → мозг).
Этот файл — только тонкий указатель, дублировать правила сюда не нужно.

Kimi-специфика:

- Среда — Windows, Bash = Git Bash (unix-синтаксис, `/dev/null`, прямые слэши).
- MCP-инструменты подгружаются лениво: `select_tools` с точными именами из анонса (`mcp__serena__*`,
  `mcp__codebase-memory__*`, `mcp__context7__*`), затем вызов напрямую.
- Разведку кодбазы делегировать сабагентам (`Agent`, тип `explore`), в основной контекст забирать
  только выводы.
